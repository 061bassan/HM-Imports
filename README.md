# HM Imports

Página de direcionamento da HM Imports, feita para quem chega pelo Instagram ou pelo WhatsApp e
precisa de um lugar só com todos os caminhos: catálogo, contato dos vendedores e localização da loja.

**No ar:** [061bassan.github.io/HM-Imports](https://061bassan.github.io/HM-Imports/)

## O que ela resolve

Loja que vende por rede social espalha informação em muito lugar. O cliente pergunta o preço no
direct, pede o catálogo, quer saber onde fica. Esta página junta tudo num link só, que cabe na bio do
perfil e abre rápido no celular, que é de onde quase todo mundo chega.

## Como foi feita

HTML, CSS e JavaScript puros, sem framework e sem etapa de build. A escolha foi deliberada: a página
tem meia dúzia de blocos e precisa carregar em rede ruim, então qualquer biblioteca seria peso sem
troco. Publicada direto pelo GitHub Pages.

```
index.html   estrutura e conteúdo
style.css    estilo, com a paleta da marca
script.js    interações da página
```

## Rodando localmente

Abra o `index.html` no navegador. Não há dependência para instalar nem servidor para subir.
